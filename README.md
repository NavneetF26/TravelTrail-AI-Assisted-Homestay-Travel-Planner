# TravelTrail: AI-Assisted Homestay & Travel Planner

An AI-assisted homestay booking and travel planning platform designed to help travelers explore homestay information, check room availability, and submit booking requests through a simple and user-friendly interface. It also integrates AI to suggest nearby attractions and generate personalized travel plans based on the user's destination, budget, trip duration, and interests.

## Tech Stack

- Frontend: React.js
- Styling: Tailwind CSS
- Backend: Express.js
- Database: MongoDB

## Features

- Homestay Information
- Room Availability
- Booking Request System
- AI-Assisted Travel Planning
